# Syracuse coffee competitors

Three **fictional** cafés built for IST356 Assignment 07 (web scraping):

- [Lakeshore Lattes](https://ist356.github.io/coffee-rivals/lakeshore/) — menu cards
- [Hilltop Grind](https://ist356.github.io/coffee-rivals/hilltop/) — menu tables
- [Canal Street Coffee](https://ist356.github.io/coffee-rivals/canal/) — order-ahead app (JavaScript)

The cafés, menus and prices are made up. The same files ship in the assignment repo
(`site/`), where the autograder serves them locally.

These pages are generated by `tools/build_sites.py` in the assignment's solution repo —
edit there and copy the output here; don't hand-edit.
